## 二、模块划分

```
contest2026_307_justdoit/app/campus_agent/
├── Kconfig                 # 构建配置
├── Makefile / CMakeLists   # 构建脚本
```

### 模块职责

| 模块 | 职责 | 依赖 |
|------|------|------|
| `main.c` | 命令解析、模块初始化、后台任务管理 | 所有模块 |
| `course_manager` | 课程表数据存储、按星期/时间查询下一节课 | RTC |
| `reminder_engine` | 定时检查课程表、触发震动+弹窗 | course_manager, RTC, PWM, LVGL |
| `sedentary_monitor` | 读取 IMU、计算运动状态、触发告警 | IMU, PWM, LVGL |
| `ui_popup` | 全屏弹窗（复用 day2_ui 的 popup 组件） | LVGL |
| `ui_briefing` | 今日课程列表页面 | LVGL, course_manager |

## 三、功能流程

### F1 课程定时提醒

```
main() 启动
  │
  ├─ 初始化 RTC
  ├─ 初始化 LVGL + 中文字体
  ├─ 加载课程表 (course_manager_init)
  │
  └─ 启动提醒引擎 (reminder_engine_start)
       │
       ├─ 每 60 秒检查一次当前时间
       ├─ 对比课程表，找到下一节课
       ├─ 如果距上课 ≤ 15 分钟且未提醒过：
       │    ├─ 震动 (vibrate: 三短震, 200ms x 3)
       │    └─ 弹窗 (popup: 课程名 + 地点 + 时间)
       └─ 循环
```

### F2 每日简报

```
用户触发 / 开机自动显示
  │
  ├─ 读取 RTC 日期和星期
  ├─ 从课程表获取今天的课程
  ├─ 在屏幕上显示列表：
  │    📚 08:00-09:35 高等数学 教学楼A302
  │    📚 10:00-11:35 大学英语 外语楼B105
  │    ...
  └─ 如果今天没课 → 显示"今天没有课，休息一下吧"
```

### F3 久坐主动告警

```
sedentary_monitor_start()
  │
  ├─ 每 5 分钟读取 IMU 加速度 (x, y, z)
  ├─ 计算滑动窗口内的加速度方差
  │
  ├─ 方差 < 阈值（静止）→ 累计久坐时间 +5 分钟
  ├─ 方差 ≥ 阈值（运动）→ 重置久坐时间为 0
  │
  ├─ 久坐 30~59 分钟 → 轻提醒
  │    └─ 单次长震 (1000ms, amplitude=150)
  │
  ├─ 久坐 ≥ 60 分钟 → 强提醒
  │    ├─ 两轮三短震 (200ms x 3, amplitude=255, 间隔1s)
  │    └─ 弹窗 "你已连续久坐 N 分钟，起来活动一下吧"
  │
  └─ 用户确认后重置久坐时间
```

## 四、数据结构

```c
/****************************************************************************
 * 课程信息
 ****************************************************************************/

typedef struct {
  int         id;
  const char *name;         /* 课程名称 */
  const char *location;     /* 教室地点 */
  int         weekday;      /* 1=周一 ... 5=周五 */
  int         start_hour;   /* 开始时 (8-20) */
  int         start_min;    /* 开始分 (0/5/10/...) */
  int         end_hour;     /* 结束时 */
  int         end_min;      /* 结束分 */
  int         remind_min;   /* 提前几分钟提醒 (默认15) */
} course_t;

/****************************************************************************
 * 久坐状态
 ****************************************************************************/

typedef struct {
  int sitting_minutes;      /* 累计久坐分钟数 */
  int alert_level;          /* 0=正常 1=轻提醒 2=强提醒 */
  int last_alert_time;      /* 上次告警时间 (epoch) */
  float accel_variance;     /* 最近一次加速度方差 */
} sedentary_state_t;

/****************************************************************************
 * 告警级别
 ****************************************************************************/

#define ALERT_NONE       0   /* 正常 */
#define ALERT_LIGHT      1   /* 轻提醒 (30-59分钟) */
#define ALERT_STRONG     2   /* 强提醒 (≥60分钟) */
```

## 六、硬件接口映射

| 外设 | 设备节点 | 用途 | 调用方式 |
|------|----------|------|----------|
| RTC | `/dev/rtc0` | 获取当前时间 | `ioctl(RTC_RD_TIME)` |
| 震动马达 | PWM2 | 提醒震动 | `ioctl(PWM_SET_OUTPUT)` |
| IMU (LSM6DSL) | `/dev/lsm6dsl0` | 久坐检测 | `ioctl(SNIOC_LSM6DSLSENSORREAD)` |
| LCD | `/dev/lcd0` | 屏幕显示 | LVGL 框架 |
| 触摸 | `/dev/input0` | 弹窗确认 | LVGL 事件 |
| UART1 | `/dev/ttyS0` | CLI 调试 | NSH shell |

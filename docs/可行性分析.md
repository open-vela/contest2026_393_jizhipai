# Vela 校园随行 Agent — 可行性分析

## 一、项目概述

**项目名称**：Vela 校园随行 Agent

**一句话定位**：面向在校大学生，基于 openvela + ai_agent 框架，在立创·黄山派开发板上实现「课程定时提醒 + 久坐主动告警 + CLI 智能对话」的随身主动提醒助手。

**核心差异化**：不是被动问答的语音助手，而是「主动感知 + 自动执行」的 Agent。到点自己提醒，超阈值自己告警，不需要用户唤醒和提问。

### 2.3 至少 1 个「主动 + 执行」场景 ✅ 可行（计划 2 种主动类型）

#### 2.3.1 定时主动：课程课前提醒 + 每日晨间简报

**技术路径**：ai_agent 内置 `cron_service` + `tool_cron`，支持 `at`（一次性）和 `every`（周期性）两种调度。

- `cron_add` 工具：创建定时任务，支持 `schedule_type: "at"` + `at_epoch` 或 `schedule_type: "every"` + `interval_s`
- `cron_list` 工具：列出所有定时任务
- `cron_remove` 工具：删除定时任务

**闭环流程**：

```
感知：cron_service 检测到当前时间 = 课程开始前 15 分钟
  ↓
决策：Agent 匹配 course-reminder Skill，确定需要提醒
  ↓
执行：vibrate（三短震）+ run_shell(my_ai_tool popup "课程提醒" "15 分钟后有《数据结构》课")
```

**关键证据**：

- `packages/ai_agent/src/tools/tool_cron.c` — 完整的 cron 工具实现
- `packages/ai_agent/src/infra/cron_service.c` — cron 调度服务
- 支持 `at_epoch`（一次性触发）和 `interval_s`（周期触发）

#### 2.3.2 阈值主动：连续久坐超时分两级告警

**技术路径**：利用 LSM6DSL 六轴 IMU 驱动（已启用 `CONFIG_SENSORS_LSM6DSL=y`），通过定时读取加速度数据判断运动状态。

**闭环流程**：

```
感知：定时任务每 5 分钟触发，读取 IMU 加速度数据
  ↓
决策：计算加速度方差，低于阈值 → 判定为久坐
      累计久坐时间 < 60 分钟 → 轻提醒（单次长震）
      累计久坐时间 ≥ 60 分钟 → 强提醒（两轮三短震）
  ↓
执行：vibrate + run_shell(my_ai_tool popup "久坐提醒" "你已连续久坐 60 分钟")
```

**IMU 数据获取方案**：

- 方案 A（推荐）：通过 `run_shell` 工具执行自定义命令读取 `/dev/lsm6dsl0`，解析加速度数据
- 方案 B：编写独立的 IMU 读取应用，定时写入状态文件，Skill 通过 `read_file` 读取

**关键证据**：

- `nuttx/drivers/sensors/lsm6dsl.c` — LSM6DSL 驱动已内置
- `apps/examples/lsm6dsl_reader/lsm6dsl_reader_main.c` — 完整的 IMU 读取示例
- defconfig 第 203 行：`CONFIG_SENSORS_LSM6DSL=y`
- `packages/ai_agent/src/tools/tool_control.c` — vibrate 工具实现（支持 duration_ms 和 amplitude 参数）

## 四、硬件资源评估

### 4.1 SF32LB525 资源

| 资源 | 规格 | 预估占用 | 余量 |
|------|------|----------|------|
| Flash | 16MB (QSPI) | 固件 ~8MB | ~8MB 余量 |
| RAM | ~256KB（估算） | ai_agent ~100KB + LVGL ~50KB + 系统 ~80KB | ~26KB |
| 外设 | I2C×2, SPI×1, UART×2, PWM×2, GPIO | IMU(I2C) + LCD(SPI/QSPI) + 触摸(I2C) + 震动(PWM) | 充足 |

### 4.2 内存优化策略

ai_agent 框架支持 Kconfig 模块裁剪，建议关闭不需要的模块以节省 RAM：

```
CONFIG_AI_AGENT_FEISHU=n          # 关闭飞书（省 ~108KB）
CONFIG_AI_AGENT_WEIXIN=n          # 关闭微信（省 ~45KB）
CONFIG_AI_AGENT_MQTT=n            # 关闭 MQTT（省 ~15KB）
CONFIG_AI_AGENT_NODE=n            # 关闭多节点（省 ~20KB）
CONFIG_AI_AGENT_MCP=n             # 关闭 MCP（省 ~25KB）
```

关闭后预估节省 ~213KB RAM，CLI-only 最小配置下 ai_agent 仅需约 50-60KB RAM。

### 4.3 外设接口映射

| 外设 | 接口 | defconfig 配置 | 用途 |
|------|------|----------------|------|
| LSM6DSL IMU | I2C1 | `CONFIG_BSP_USING_I2C1=y` | 久坐检测 |
| CO5300 AMOLED | QSPI/LCDC | `CONFIG_BSP_USING_LCDC=y` | 屏幕显示 |
| FT6146 触摸 | I2C | `CONFIG_INPUT_FT6146=y` | 触摸交互 |
| 震动马达 | PWM2 | `CONFIG_BSP_USING_PWM2=y` | 震动提醒 |
| TF 卡 | MMCSD | `CONFIG_MMCSD=y` | 数据存储 |
| UART1 | UART | `CONFIG_BSP_USING_UART1=y` | CLI 调试 |

## 五、风险评估与应对

### 5.1 中等风险

| 风险 | 影响 | 概率 | 应对方案 |
|------|------|------|----------|
| RAM 不足 | ai_agent + LVGL + 应用同时运行可能 OOM | 中 | 关闭不需要的 ai_agent 模块（飞书/微信/MQTT/MCP/Node）；LVGL 使用静态缓冲区；Skill 按需加载 |
| IMU 久坐判定精度 | 误判或漏判 | 中 | 使用加速度方差而非绝对值；设置合理的阈值和滑动窗口；提供手动重置命令 |
| LLM 断网降级 | F4 智能对话断网时不可用 | 高 | 设计离线关键词匹配降级方案；F1/F2/F3 核心功能纯端侧不依赖网络 |

### 5.2 低风险

| 风险 | 影响 | 概率 | 应对方案 |
|------|------|------|----------|
| cron 任务数量上限 | 课程多时可能超限 | 低 | 合并同类型任务；使用 every 类型替代多个 at 类型 |
| 弹窗显示冲突 | 多个提醒同时触发 | 低 | 设计弹窗队列机制，依次显示 |
| 中文字体渲染 | FreeType 渲染中文可能有性能问题 | 低 | 预渲染常用字符；使用小字号 |
